## 🌐 Ecossistema LiberNet

### 🤖 [Sofia](https://sofia.libernet.app) - IA Descentralizada
Primeira inteligência artificial nativa da rede Nostr com autenticação descentralizada.
- **Tech:** Python, Flask, GPT-4o, Nostr, Lightning Network
- **Features:** Login Nostr (nsec/nos2x), Machine Learning, RAG, Pagamentos Lightning
- **Repo:** [sofia-web](https://github.com/lucianocasalunga/sofia-web)

### 📡 [Relay](https://relay.libernet.app) - Relay Nostr
Sistema de relay Nostr com pagamentos Lightning e retenção de dados.
- **Tech:** Python, Flask, Strfry, SQLite, LNBits
- **Features:** NIP-40 (retenção), 6 planos de assinatura, Moderação automática
- **Repo:** [liberrelay](https://github.com/lucianocasalunga/liberrelay)

### 🎥 [LiberMedia](https://media.libernet.app) - Hospedagem Descentralizada
Plataforma de hospedagem de arquivos na rede Nostr.
- **Tech:** Python, Flask, PostgreSQL, Nostr
- **Features:** NIP-96 (upload), NIP-05 (identidade), Thumbnails WebP, PWA
- **Repo:** [libermedia](https://github.com/lucianocasalunga/libermedia)

### 🤖 [n8n](https://n8n.libernet.app) - Automações
Plataforma de automação de workflows para o ecossistema.
- **Tech:** n8n, Docker, SQLite
- **Features:** YouTube → Telegram, RSS → Nostr, Multi-plataforma
- **Repo:** [n8n-libernet](https://github.com/lucianocasalunga/n8n-libernet)
